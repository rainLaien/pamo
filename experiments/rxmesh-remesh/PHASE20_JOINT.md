# 第二十阶段：有界联合质量评价

## 本轮范围
只修改评价与可选接受路径，没有生成新网格，也没有重跑 GPU 或原始 STL 完整流程。默认入口仍保留既有严格策略；显式 -RegionalQualityPolicy 开启联合区域损失预算策略。本轮不替任何候选事后挑选一个刚好能通过的预算，也不修改几何误差和特征约束。

## 联合评价方法
以有实际连接关系的“目标区＋必要邻区”作为事务。不同连通事务不能互相抵销损失；当前实现对一个 patch 内含多个断开部分的事务要求进一步组件化，拒绝直接联合接受。

主诊断为缺陷严重度 D = Σ A_f max(0,1-q_f/q0)，使用输出 float32 坐标的 double 运算。q0 延续对照 cutoff=0.026690566912293434，D 单位为面积；它反映低质量面积与低质量程度，降低三角形数量变化和 cutoff 跨越造成的误判，但并不是完整业务效用函数。另列 q0/4 的尾部面积，仅用于严重尾部诊断，不能当作通用质量标准。

不再在可选联合模式中要求每个邻区的均值、P05或面积加权质量单独不下降。均值与P05保持报告，按面数的统计不作为单独否决项。

显式预算包括：邻区缺陷损失/改善收益比、联合面积加权质量损失、最大低质量连通面积增长、退步邻区最终最大低质量组件面积、严重尾部面积增长、面数增长。另需原生尺寸场的短边增长预算，禁止新增长边数量。各预算单位与用途在报告中明确，不能用全局 h 统计替代原生尺寸场。

### 当前判断
候选升级为值得评估有界取舍的对象，不能再仅因邻区任一均值下降就否决。但尚未接受：下游用途和业务损失预算未明确；已有候选未导出实际原生尺寸场，也未完成本轮原始输入几何/特征/法向独立复核。程序会保留候选并报告缺失项。

required_budgets 是候选代价的测量下限，不是自动生成的允许预算。若采用该候选，单从质量侧至少需要允许10.824%的邻区损失/收益比、0.035958的联合加权质量损失、0.464251的退步邻区最大组件面积及3828个新增三角形；这只是供评审的条件，不能作为事后通过理由。

## 实现
- tools/joint_region_quality.py：联合指标、空间组件检查、有界损失评价。
- compare_regional_candidate.py：--joint-quality-policy 与 --native-size-evidence。已有严格接受路径仍可独立比较；新路径要求质量、拓扑/特征、原始几何预算和原生尺寸证据全部通过才可采用区域事务。
- run_raw_partition.ps1：-RegionalQualityPolicy/-NativeSizeEvidence，并记录策略位置；候选失败时保留已完成参考结果和可继续处理的候选。
- tests/test_joint_region_quality.py：有界邻区退步、无预算不接受、各预算生效、无进步不接受、无效预算、断开区域以及硬约束不被取舍覆盖。

原生全模型 endpoint 判断尚未迁移到联合预算策略。可采用区域事务不等于全模型已验收，也不把 native_quality_accepted 的失败改为成功。这是本次范围的限制。

策略 JSON 使用 quality_limits（6个明确数值）、native_short_edge_growth_max（非负整数）及 justification（预算依据）。原生尺寸证据 JSON 包含 baseline/candidate 两份 audit_native_fields 输出，各自 SHA256 必须绑定对应网格。缺证据不采用。未提供默认生产预算。

## 验证与性能
9项联合策略测试＋10项既有审查测试通过，PowerShell 入口语法通过，实验目录 diff --check 通过，9段无关修改与初始快照一致。重新评价耗时 3.808秒，是复用结果的诊断时间，不是完整流程时间。本轮没有算法运行耗时改善结论。

此前完整流程仍为：不含审查数据导出的107.39秒对照，以及启用数据导出的116.20秒单次对照；本轮不能用几秒诊断宣称达到90秒。
