# 区域候选集成与完整流程结果

结论：候选流程已经接入、可独立开启和回退；**1.9 和 0.95 两种候选均被拒绝**。窄带本身改善，但邻域及同一计算任务中的其他片区退化，不能接纳为最终结果。最终发布的 `remeshed.ply` 保留第一阶段结果，失败候选单独保存，没有退回原始 STL。没有达到 90 秒目标。

## 改动范围

- `tools/repair_narrow_strips.py`：可选 JSON 区域尺寸覆盖；相连的待重建条带使用同一较小尺寸及统一采样网格；复用原有邻面同步、拓扑、原始锚点、特征边和开边界检查。默认尺寸网格保持原样。已有不可变源缓存保留。
- `tools/compare_regional_candidate.py`：比较不可变参考结果与候选；检查全局、几何邻域及实际变化的全部片区；检查保护特征链、接缝链、拓扑、相对原始 STL 的双向距离采样和所属源片区参考方向。
- `run_raw_partition.ps1`：显式实验开关、固定参考诊断截止值、验收和区域事务回退。拒绝时复制参考 remesh 到最终输出，保留新候选、原始批处理报告及比较报告。退出 4，不宣称成功。
- 已有 Python 测试：覆盖相连尺寸传播、同步、缓存参数一致性、快照绑定、面积加权损失、变化范围、方向和事务/端点状态。

未改分区、GPU 算子、接缝调度或重建器 `narrow_strip_geometry.py`。当前 GPU 可执行文件与第一阶段 SHA256 相同：`ebddb3338123879bc4f995c0a0d9397a554ef58047cac33e438914cd5106e72f`。既有壁厚修改和 RXMesh.log 经与接手时差异对比保持一致。未提交、未推送。

## 接受、回退和继续处理

区域配置只指定候选尺寸，不赋予接受权限。相连条带的尺寸取选中覆盖值与默认值的较小值，避免两侧站点不同；非条带邻面仍使用原有同步三角化。本次同步要求把 3817 纳入区域重建，因此实际缩小尺寸的片区为 3816、3817、3842、3843。

实际 GPU 输出可能超出几何一环。比较器通过与参考结果逐片区比较有向三角形坐标，枚举全部变化；循环置换及面顺序不构成变化，反转方向会被识别。全部实际变化片区都进入评价，不能仅报告预先选择的三个片区。

`regional_candidate_accepted` 表示区域及实际受影响片区的质量/硬检查通过；`regional_transaction_adoptable` 还要求全局质量不退化和区域几何检查通过。可采用的中间候选也不自动满足端点：`endpoint_accepted` 另要求原始输入双向误差采样及原生最终验收通过。已有其他端点缺陷不会自动抹掉合格的中间进展，但退出状态仍为 4；未通过区域事务检查则保留参考 remesh。

质量非退化比较包括 mean、P05、面积加权质量、低质量面积和最大低质量区域面积。原有低质量目标片区还需至少一项可测改善；健康邻区可以不变。数值质量容差 `1e-6`、缺陷面积比较容差为对应参考缺陷面积的 `1e-6`（最小 `1e-12`），本次作为保守实验比较检查。它们不是通用工程合格阈值。

实验覆盖最多 32 个相连重建片区、最多 50000 个区域重建面，沿用原有单条带 4096 站点和 8 次邻域扩展上限。这些是防止实验无界扩展的工作预算，不是质量目标。失败报告及候选留存供后续处理，不把拒绝当作问题已解决。

区域配置可绑定源快照 SHA256；提供的两个实验配置均已绑定，识别预算或原始输入变化后会拒绝使用原 patch ID。还需进一步形成基于宽度、曲率和特征间距的通用触发规则，本阶段没有把三个 ID 写成通用算法。

## 特征、拓扑、方向和几何

两种候选全局保护特征链、源接缝链、开边界链的缺失锚点/缺失连接均为零。非流形、绕向不一致、重复面、float32 零面积面均为零；全局连通分量、Euler 与源一致。快照特征标签的真实几何来源仍未知，不能把这一检查描述成完整 CAD 特征认证。

参考方向异常不是严格的真实翻转证明。1.9 在 3811 新增一个非正参考法向点积面心；0.95 在 3811 新增一个，3815 从一个增至三个。依据第一阶段全量检查 464 个异常，并替换全部实际变化片区的计数，推导候选全量分别为 465、467；有向三角形未变化片区已经核对。这一推导及依据保存在 comparison.json，不能宣称零翻转。

输出→原始 STL 最大采样距离为 1.0532 / 1.3331；原始 STL→输出均为 **1.53979，仍超过 1.524741 的预算**。反向使用相同原始表面随机种子和样本；输出侧样本依赖候选网格，不能把采样最大值下降视为全局 Hausdorff 改善证明。

继续核查 4790：它是 Freeform，源有 2255 个面，没有可用的解析曲面参数。此前定位的失败样本在分区/修复快照误差接近零，在旧版、第一阶段及两种区域候选中仍为 1.53979。`RawCudaRemesher.cu` 的 `AuditGeometryUnique` 检查输出顶点、边中点、面心到源参考的距离；它没有检查源表面到输出的覆盖距离。这解释了现有检查不能认证双向预算，但尚未隔离具体是哪一个算子产生缺口。本轮未修改该算子。

## 残留问题与下一步范围

1. 窄带本体收益成立，整邻域方案失败。下一步先针对 607/982 的边界细采样到内部粗网格过渡生成有成本上限的邻域候选，并在 GPU 前后分别评价；不继续无条件减小条带尺寸。
2. 任务整体选择与片区评价存在耦合。先增加诊断、确认选择周期导致的变化，再决定最小修正；本轮没有重写任务划分或接缝调度。
3. 4790 要单独隔离原始覆盖误差，建立源→输出的区域覆盖检查。不能提高误差预算或用窄带收益抵消这个失败。
