# 第九轮：逐区域选择与已达标区域复用

自动优化目标仍未完成。第八轮整任务候选均未采用，本轮在同一可选候选比较路径上逐 patch 选择，并保持整体连通缺陷检查；没有修改几何预算、诊断阈值、GPU 编辑算子、分区、接缝调度或窄带重建方法。默认开关仍关闭。

## 机制

1. 保留合法任务候选，记录原始区域和候选的 patch 质量。
2. 没有低质量面且相对原始区域通过质量验收的 patch 复用当前候选。其余 patch 继续原有单 patch 恢复路径，不将困难区域标成成功。
3. 每个恢复候选须在均值、P05、面积加权质量、低质量面积、最大低质量连通面积及长短边数上不退化，并有可测质量进展；否则保留该区域的合法候选。
4. 只按不可变源锚点 ID 拼合，内点不按坐标合并。重新检查拓扑、逐 patch 指标和跨 patch 的连通缺陷；整体退化则保留整个合法当前候选。
5. 最终装配区域审查决定 endpoint 状态；发生选择本身不表示质量验收通过。

报告增加生成及采用区域数、比较前后质量、拒绝原因和候选策略。选中混合候选后重新填入其质量及尺寸统计；几何报告使用合法当前候选与选中子候选的保守最大误差，不把未选候选的失败误差算成最终几何误差。操作计数标明是当前候选加选中子候选的尝试计数，不能当作最终网格差分计数。

文件：`src/RawCudaBatch.cpp`、`include/cad_adaptive/RawCudaBatch.h`、`tools/raw_partition_cli.cpp`、`tools/compare_regional_candidate.py`、`tests/test_raw_batch.cpp`。

## 原始 STL 完整结果与独立对照

完整流程 **150.6809 秒**：首次窄带修复 9.545 秒，batch 90.6600 秒，后续修复检查 2.330 秒；分区打包及全部读取和输出也包含在总耗时内。生成 1676 个子候选、73 个任务采用共 142 个区域，输出 497107 面，fallback=0、unchanged=40。原生质量验收仍失败。新旧修复输入 CADPART 的 SHA256 完全相同，尺寸、预算、迭代、平滑等参数保持一致。

原生局部目标统计有 **394 条长边**。第十轮补查确认默认对照也有相同 394 条局部长边；它们不是本轮混合候选新增的缺陷。不能用全局 h 的零长边掩盖局部目标缺陷。后续证据表明恢复区域选择依赖局部任务报告，遗漏了装配后按较小目标产生的缺陷；第十轮已针对实际装配网格选择恢复区域。共享边界目标检查虽然发现未采用候选的不一致，但不改变本轮输出，不能将其归因于已采用候选。

独立审查耗时 23.8636 秒，在完整输出之后运行，另计。实际几何变化 140 个 patch；全局质量五项均非退化，但 **3 个 patch 退化**：4500 均值 0.0328465→0.0307716；5712 最大低质量面积增加约 6.7e-6；5844 低质量面积增加约 4.7e-6。后两项虽小仍按同一独立规则判为退化，没有放宽统计口径。局部候选与最终装配指标差异尚需定位，不能采用为最终结果。

原始 STL 双向采样最大误差 1.267034 / 1.304286，均在 1.524741292 预算内，仍非连续几何证明。修复输入上的 92885 条特征链、92105 条接缝链和 81 条开放边链无缺失；锚点误差小于 7.1e-7。该链数基于**修复后输入**，不能与第五轮原始快照的链数混为同一对象。输出连通分量 1、Euler=-1，非流形、重复、float32 零面积和内部绕向冲突为零。

所有 140 个实际变化区域的参考方向异常从 3 面降为 0，无新增区域方向异常；其余区域几何不变，已有异常仍存在。这个检查不能证明全网格没有实际翻转或自交。227 个窄带重建均执行；重点困难区域中 3842 有改变，3816、3843 未改变。它们的继续处理路径仍保留，不能称已解决。

结果及同口径对照在 `results/phase9_defects/full_mixed`、`full_comparison.json`。比较器原用于显式区域重建，本轮未声明该类区域目标，因此 `outside_declared_neighborhood=140` 是该接口缺失声明的结果，不能解释为出现了未检查变化。审查实际上使用所有实际变化区域，不因声明为空跳过它们。最终仍因原生 endpoint、局部尺寸及逐区域退化失败。

3842 的独立均值仅 0.0262012→0.0262250，面积加权均值 0.0243201→0.0243470；P05=0.0069627、低质量面积=59.7702 和该 patch 最大连通面积=49.2564 均未改善。这是小幅操作收益，不能当作窄带质量问题已解决。

24 个针对性测试通过，九项无关 tracked 修改与初始 diff 一致。保存了最新诊断程序和 tracked remesh 检查点；后者不包含未跟踪文件，不是完整备份。
