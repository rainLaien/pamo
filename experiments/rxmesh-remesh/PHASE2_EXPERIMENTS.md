# 第二阶段局部尺寸实验

本轮验证了局部缩小尺寸对真实窄带的收益，并定位第一阶段原始表面误差超预算的区域。新增两个离线实验工具和两个测试；生产算法、参数默认值、分区、GPU、装配与局部重建器未改动。没有提交或推送。

## 范围与比较口径

固定原始 `2.stl` 分区快照，选择最大差区域涉及的 patch 3842、3843、3816。复用现有 `narrow_strip_geometry.remesh`，分别从同一个源片区生成候选，不连续细分上一次结果。使用现有修复器的统一采样网格相位规则，选择集合固定为上述三个片区；它与生产修复器选择全部条带时的相位不一定一致。

这是**局部参数实验**，不是生产算法改善对照。比较目标 7.623706、1.9、0.95、0.475；质量公式、截止值 `0.02669056691`、误差预算 `1.524741292` 相同。边界链数值容差与第一阶段全局独立审计一致，为 `7.623706345e-5`，所有候选固定使用该值。候选先转 float32，再审计。

快照提供的保护特征链、原始边界链、片内折线分别检查；同时检查退化、重复面、非流形、绕向、连通分量、Euler、参考方向、相对面积变化和双向距离采样。面积相对误差 `1e-5` 是本离线筛选的保守检查值，没有标定为通用工程合格线。双向距离是采样，不能证明 Hausdorff 上界；原始锚点和三角形中心也参与反向采样。

## 定量结果

低质量面积相加包含三个片区全部低质量面；它不是跨片区最大连通区域面积。局部没有装配，因此不能宣称整网格连通缺陷已经消除。

| 候选 | 三片区面数 | 低质量面积合计 | 局部检查 | 选中接口采样集合 |
|---|---:|---:|---|---|
| 第一阶段生产输出（参考） | 801 | 153.4545 | 此处不重新认证 | 此处不重新认证 |
| 相同重建器，目标 7.623706 | 810 | 149.2993 | 部分失败 | 一致 |
| 相同重建器，目标 1.9 | 3,194 | 2.6351 | 三片区通过 | 一致 |
| 相同重建器，目标 0.95 | 6,370 | 0.6698 | 三片区通过 | 一致 |
| 相同重建器，目标 0.475 | 12,712 | 0.1667 | 三片区边界链失败 | 一处不一致 |

与相同重建器的 7.623706 候选相比，1.9 降低低质量面积约 98.2%，0.95 约 99.6%。不能将与第一阶段生产输出的全部差异仅归因于目标尺寸，因为独立局部生成和统一网格选择集合也不同。

目标 0.95 对第一阶段片区输出的比较：

| patch | mean 前→后 | P05 前→后 | 面积加权质量前→后 | 低质量面积前→后 |
|---|---|---|---|---|
| 3842 | 0.02620→0.17974 | 0.00696→0.05594 | 0.02432→0.19013 | 59.7702→0.1777 |
| 3843 | 0.01573→0.09520 | 0.00201→0.00941 | 0.01954→0.12491 | 6.2661→0.1807 |
| 3816 | 0.02454→0.17785 | 0.00674→0.04887 | 0.02429→0.18923 | 87.4182→0.3115 |

三个片区的保护特征链、边界链、折线链缺失均为零，原始锚点误差零。非流形、重复面、绕向错误、float32 零面积面和非正参考法向点积均为零，局部连通分量和 Euler 与源一致。双向样本最大误差小于 `7e-6`。这是针对源片区的局部证据，不替代整网格对原始 STL 的完整审计。

3843 的 P05 仍低于诊断截止值，三个片区仍有低质量面；原始锚点、薄端部、折线连接不能通过增加面数消失。目标 0.475 有明确链和接口失败，即使质量数值更好也不采用；尚未确认失败属于几何量化还是重建连接问题，没有放宽检查。

## 尺寸、成本与各向异性

现有边界站点重建没有增加完整横向网格层。目标 0.95 是沿条带采样的控制参数，不代表所有边均趋近 0.95。按新局部目标检查仍有 3263 条过短边；按原全局 7.623706 检查有 10757 条过短边，两者都记录，不能通过换统计目标掩盖短边。计数为三个片区边数相加，共享边可能重复，不是装配网格的唯一边数。

三个局部候选的生成及审计合计约：1.9 为 1.01 秒，0.95 为 1.88 秒，0.475 为 3.67 秒。它们不包括读入、统一接口集合检查、邻接同步、GPU、整网格装配和输出；也不是完整流程耗时。没有使用这些数字宣称满足 90 秒。生产流程仍是第一阶段实测的 102.65 秒。

1.9 已有很大缺陷面积收益，面数约为参考输出的 4 倍；0.95 约 8 倍。可先把 1.9 作为有成本上限的候选，只有区域验收仍失败且允许新增面数时继续 0.95。当前两个值来自实验扫描，不是普遍窄带规则。推广时需要横向有效宽度、曲率、特征间距及相邻尺寸过渡共同决定局部场，不能按 patch ID 固化参数。

各向异性允许较长的纵向边，能减少面数，但欧氏三角形质量仍可能偏低。后续若采用各向异性，需要另给方向场及其质量指标，并保留现有欧氏质量、短边和连通缺陷报告；不能换成各向异性统计后宣称当前低质量问题已消失。本轮没有新增各向异性算子。

## 接口和误差定位

统一采样后，目标 1.9/0.95 的选中区域接口采样点完全一致；这只是局部点集合检查，未装配、未验证完整接缝。还涉及邻接 patch：489、607、982、3811、3817、3818、3824、3841、3844。下一次候选必须复用现有邻面同步机制，记录影响范围，并重新检查这些邻域的质量与几何。不能直接替换三个片区而留下 T 接点。

复查第一阶段保存的两处原始表面最差样本：

| 样本所属区域 | 分区快照误差 | 条带修复快照误差 | 旧输出误差 | 第一阶段输出误差 |
|---|---:|---:|---:|---:|
| patch 3561 | 约 0 | 约 0 | 2.18806 | 0.01375 |
| patch 4790 | 约 0 | 约 0 | 1.53979 | 1.53979 |

这两个样本处的误差出现在后续 remesh 链路，不是条带预处理累计误差；不能由两点推断所有区域的误差来源。4790 与此次条带候选不同，仍超过 1.524741 的统一预算。下一步需要在此区域隔离 collapse/smooth/projection 等阶段，区分源参考覆盖不足与算子误差；当前尚未证明具体算子是根因。

## 复现

从仓库根目录运行，路径引用第一阶段保留的实验数据：

```powershell
python experiments/rxmesh-remesh/tests/test_phase1_audit.py
python experiments/rxmesh-remesh/tools/sweep_strip_sizes.py `
  --snapshot experiments/rxmesh-remesh/results/phase1_20260926/baseline/full_fast/input.cadpart `
  --reference-ply experiments/rxmesh-remesh/results/phase1_20260926/new/full_release/remeshed.ply `
  --threshold 0.02669056691 --max-error 1.524741292 `
  --targets 7.623706340789795 1.9 0.95 0.475 --shared-grid `
  --output experiments/rxmesh-remesh/results/phase2_strip_shared

python experiments/rxmesh-remesh/tools/trace_geometry_witnesses.py `
  --audit experiments/rxmesh-remesh/results/phase1_20260926/independent_audit.json `
  --snapshot experiments/rxmesh-remesh/results/phase1_20260926/baseline/full_fast/input.cadpart `
  --repaired experiments/rxmesh-remesh/results/phase1_20260926/baseline/full_fast/strip_repair/pass_01/input.cadpart `
  --baseline experiments/rxmesh-remesh/results/phase1_20260926/baseline/full_fast/remeshed.ply `
  --candidate experiments/rxmesh-remesh/results/phase1_20260926/new/full_release/remeshed.ply `
  --output experiments/rxmesh-remesh/results/phase2_strip_sweep/geometry_witnesses.json
```

结果：`results/phase2_strip_shared/sweep.json`，各局部候选为同目录 `.npz`，误差点追踪为 `results/phase2_strip_sweep/geometry_witnesses.json`。NPZ 不可当作完整 remesh 输出。第一阶段回退补丁不包含本轮新增工具和测试，继续修改已有测试后重新回退需要重新审查补丁。
