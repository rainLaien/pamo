# 独立通用 remesh 实验

入口：`cad_mesh_generic`；脚本：`examples/remesh_generic.ps1`。
默认模式绕过曲面分类、解析 patch 拟合、参数域三角化和 patch 接缝重建。
可选 `-AnalyticGuides` 仅接入局部圆柱/圆锥几何引导，见 `GENERIC_ANALYTIC_GUIDES.md`。
使用原始 STL 清理后的三角网格作为固定几何参考，直接修改网格拓扑。
尚未替换旧入口；当前是 CPU 串行验证实现，不能宣称已有线程池或 CUDA 加速。

## 执行

在项目根目录执行（输出目录必须未包含之前的结果）：

```powershell
.\examples\remesh_generic.ps1 -InputStl .\examples\2.stl -TargetEdgeLength 6 -MaximumDeviation 0.03
```

默认构建 Release；已有构建可增加 `-SkipBuild`。
默认 5 轮、保型法向限制 10°、尖边检测阈值 45°。
尖边检测角与保型法向限制是不同参数。可以用 `-FeatureAngle` 改前者；
直接调用程序可用 `--normal` 改后者。
目标边长 6 是普通区域的期望尺度，曲率和误差约束会缩小局部尺寸，并非全部边必须达到 6。
输入单位继承 STL，程序不推断毫米。

## 主循环及约束

1. 拓扑清理、建立不可变原始网格 BVH。边界边、非流形边和尖边成为约束。
2. 根据局部法向变化估计尺寸，并限制尺寸沿空间距离增长。
3. 短边塌缩消除冗余点；改善最小角度的内部翻边；长边中点细分；切向平滑并投影回参考。
4. 最后两轮只做塌缩、翻边和平滑，避免最后一轮新增点来不及整理。
5. 对结果进行双向确定性抽样距离检查和原始特征线段检查。

最长边达标不会跳过翻边和平滑。每轮细分有 200000 次预算，当前也没有证明收敛；
`remaining_long_edges` 是本轮细分之前的候选数，不是最终达标统计。
保型检查包含新三角形顶点、边中点、重心到参考网格的距离和法向检查，塌缩另有局部反向覆盖检查。
参考线段上的顶点固定，细分只能在线段内插值。非流形边相邻三角形保留并计入诊断。

## 输出和验收语义

- `generic_report.json`：耗时、面数、5/10/20/28° 小角度数量及面积占比、操作数、拒绝数、双向抽样偏差和特征保留数。
- `generic_result.ply`：抽样形状验收通过的候选。**文件存在并不代表质量目标已达标。**
- `generic_candidate.ply`：验收失败时保留，用于分析；程序返回非零退出码。
- `sampled_shape_audit_passed` 与 `quality_target_reached` 分开报告。普通区域还有小于 28° 的面时，后者为 false。

PLY 每个面有 `minimum_angle` 和 `issue_flags`：位 1 表示小于 28°，位 2 表示接触固定约束点，位 4 表示有几何检查拒绝历史。
这允许直接定位受约束小角度面和普通区域未解决的面。
约束邻接、几何拒绝历史都**不是**“这个小角度不可避免”的证明。
真实尖角或极窄结构处不能强行要求 28°，但当前也不能自动证明哪些面无法改善。

可选导出具体面序号和重心坐标（仅此辅助工具需要 Python，remesh 本身不需要）：

```powershell
python .\examples\export_generic_issues.py <结果目录>\generic_result.ply <结果目录>\constraint_faces.csv
# 同时输出普通区域未解决的面：增加 --ordinary
```

最终距离统计每个方向约抽取 10000 个面，检查一个顶点和重心。
这不是连续曲面的 Hausdorff 上界证明，也没有全局自相交保证。
尤其相距很近的表面，当前全局最近面查询没有同一薄壁侧约束，不能据此承诺任意 STL 的生产可靠性。

## 同模型结果与判断

模型：`examples/2.stl`，39056434 字节，清理后 781127 面。
旧流程数据来自 `examples/remesh_all_review_20260911_194759`，本次对其 ASCII PLY 重新统计了角度。
通用最终复核：`examples/generic_verified`。此前 balanced 版本耗时 187.115 秒；
加入非流形邻域保护后本次为 205.884 秒，几何质量统计完全相同，保护检查本身也增加了开销。

| 指标 | 原始网格 | 旧完整流程 | 通用最终复核 |
|---|---:|---:|---:|
| 总耗时（含 STL 读取） | — | 382.812 秒 | 205.884 秒 |
| 面数 | 781127 | 5894206 | 1354449 |
| 小于 28° 面占比 | 66.8721% | 60.2152% | 39.3404% |
| 小于 28° 面积占比 | 73.8002% | 34.7388% | 26.8062% |
| 小于 10° 面数 | 242861 | 1232596 | 101906 |
| 双向抽样最大距离 | 0（自身） | 尚无同口径测量 | 0.0235303 |
| 原始检测特征段保留 | 5412 | 尚无同口径测量 | 5412/5412 |

不能把旧流程配置的误差阈值当作其实际偏差，也不能由颜色推断特征保留。
通用结果有 532846 个小于 28° 的面，其中 15089 个接触约束点，517757 个属于普通区域。
虽然小角度**比例**改善，普通区域小角度的**绝对数量**并没有下降（输入 506614），这是明确的未达标项。

最终复核记录：600000 次细分、313337 次塌缩、588652 次翻边、1452139 次顶点移动，
3655613 次几何拒绝。197.370 秒花在局部操作循环，拓扑和索引约 5.212 秒。
因此现在的瓶颈已经不是解析分类，而是尺寸估计、重复无效操作及大量几何查询。

**结论：独立入口及可复核对照已具备；尚未证明它能作为通用生产主流程。**
下一步应先改善长瘦输入上的尺寸估计、只重试邻域变化的失败候选，并以普通区域小角度数量下降作为收敛条件。
暂时不接回解析分类，也不应先用并行掩盖重复工作。并行化后仍需重复上述几何和拓扑验证。

## 验证

```powershell
cmake --build cad_mesh/win --config Release --target cad_mesh_generic --parallel 8
python cad_mesh/tests/test_generic_entry.py
```

黑盒测试覆盖闭合圆柱细长带、开边界平面、非流形连接和非流形邻面的细分保护。
测试验证输出可解析、索引有效、相应拓扑约束保持、无零面积面、抽样距离满足限值，圆柱测试还要求小角度比例改善。
