# 通用拓扑操作与解析几何引导

## 运行方式

```powershell
.\examples\remesh_generic.ps1 -InputStl .\examples\2.stl -TargetEdgeLength 6 -MaximumDeviation 0.03 -AnalyticGuides
```

省略 `-AnalyticGuides` 即运行原通用入口；输出到不同目录可直接比较。
可执行程序对应开关为 `--analytic-guides 1`。
默认仍保留原通用模式，两个模式都使用相同的拓扑修改和 STL 保型检查。

## 实际接入内容

- 支持区发现：优先长瘦面，以长边方向一致的邻接面构造局部支持，避免种子混入顶底面和圆角。最多 4096 次候选尝试，每次约 64 面；不调用完整分类管线。
- 复用项目的 `CylinderSurfaceFitter` 和 `ConeSurfaceFitter`。接受阈值为 `min(0.02, MaximumDeviation / 4)`；还须逐个原始顶点通过距离检查、逐面法向误差不超过 5°。
- 拟合须有足够法向跨度和轴向跨度，避免把近似平面或极窄片段当作可靠的圆柱/圆锥。
- 拟合通过后，沿拓扑邻接吸收同样满足几何条件的面。不会因为长边较短就排除这些面。
- 同一顶点所有关联原始面都属于同一支持区时，允许用解析半径估计局部尺寸。接口位置继续使用通用尺寸及空间增长限制。
- 移点时提供解析投影候选。候选必须靠近原始 STL，且参考命中面仍属于该支持区；否则走原通用投影。随后仍执行所有局部操作保型检查。

解析支持区不会加入 `Features` 或 `Fixed`；没有新建分类接缝，没有分 patch 构网或事后补缝。
支持区不是完整的 CAD 曲面识别，多个局部支持区可能来自同一圆柱或圆锥。
没有改变原始尖边、开边界和非流形保护策略。

## 报告口径

`generic_report.json` 新增以下指标：

- `analytic_fit_seconds`：包含候选提取和支持区增长的识别耗时，已经包含在 setup 时间内，不能重复加总。
- `analytic_cylinders` / `analytic_cones`：局部支持区数量，不是模型中完整几何体数量。
- `analytic_supported_faces`：覆盖的原始三角面数量，不等于输出面覆盖率或面积覆盖率。
- `analytic_projection_proposals`：通过初步参考检查的投影候选次数，不保证对应的塌缩/平滑最终被接受。
- `analytic_projection_fallbacks`：解析投影初步检查不通过、转回通用投影的次数。

输出继续使用独立的抽样保型验收与质量验收字段。原 STL 是最终参考，解析拟合不能放宽距离或法向预算。
仍然是 CPU 串行实现，没有新增 CUDA 依赖；局部拟合采用现有 CPU fitter。

## 验证

`python cad_mesh/tests/test_generic_entry.py` 共 6 项测试（圆柱/圆锥测试含两个子用例）。
新增测试检查圆柱、圆锥确实产生引导投影，闭合性和顶底平面保护不变；纯平面不会产生解析引导。
原先的细长带、开边界与非流形测试继续运行。

同模型运行目录：`examples/generic_hybrid_verified`；对照目录：`examples/generic_verified`。
同一模型 `examples/2.stl`、目标长度 6、距离限值 0.03、法向限值 10°、5 轮：

| 指标 | 原通用入口 | 解析引导开启 |
|---|---:|---:|
| 含 STL 读取总耗时 | 205.884 秒 | 225.706 秒 |
| 输出面数 | 1354449 | 1358589 |
| 小于 28° 面占比 | 39.3404% | 39.2579% |
| 小于 28° 面积占比 | 26.8062% | 26.8324% |
| 普通区域小于 28° 面数 | 517757 | 518396 |
| 双向抽样最大距离 | 0.0235303 | 0.0254920 |
| 几何操作拒绝次数 | 3655613 | 3662859 |
| 检测特征段保留 | 5412/5412 | 5412/5412 |
| 输出开边界边数 / 非流形边数 | 85 / 0 | 85 / 0 |

引导识别用时 2.84674 秒；52 个圆柱支持区、231 个圆锥支持区，共覆盖 8924 个原始面。
产生 165759 次通过初步检查的解析投影候选，57786 次初步检查未通过后转回通用投影。
这里的局部支持区数量不能用来宣称完整圆柱/圆锥识别率。

本轮证明了两套能力可以在统一拓扑下结合，抽样距离验收和特征段验收通过，网格质量与原通用入口接近。
但没有测得加速或显著质量提升：总时间增加，几何拒绝次数没有下降，普通区域小角度数也略增。
这些是各一次整模型测量，不是多次重复后的稳定性能估计。
因此保留可选开关，不改变默认入口。后续需先扩大可靠支持覆盖、减少参考查询和重复失败尝试，再衡量是否值得默认启用。
