# Per-face remesh output

This supersedes the patch-wide status and post-remesh rollback descriptions in
earlier documents. PLY `remeshed` and `remesh_reason` now follow output triangles
through Freeform subregion assembly. `patch_id` remains the original partition ID.

| remeshed | Meaning |
| --- | --- |
| 0 | Not selected for this run |
| 1 | Selected region whose construction failed; original triangles retained |
| 2 | Successfully reconstructed region |
| 3 | Good input triangles deliberately preserved |

State 3 uses `remesh_reason=9` (`preserved_good_input`). Selection for preservation
uses only longest edge <= target length (with the existing 1e-6 relative numerical
slack); all edge lengths must be finite. There is no area, quality, angle or
connected-face-count threshold. Connectivity is counted for logging only.
State 3 does not mean that every newly generated good
triangle is relabeled, or that unselected patches were processed. Analytic patches
still use their chart construction path; this preservation selector is Freeform.

Successful Freeform subregions are published even when all other repair regions
fail. Failed regions retain their own reasons rather than inheriting the parent's
success. Per-face counts are logged as `remesh face status`. Patch summary counters
remain legacy aggregate processing summaries; use face counts/attributes for
mixed results.

Removed the final Freeform vertex/edge/centroid reference-deviation rejection,
the second reference-deviation check after local analytic reconstruction, and
the assembled-mesh collision/replay/whole-patch rollback pass. No new collision
diagnostic pair files are generated by that removed pass. Construction-time
projection, local operation constraints, boundary/topology validation, and model
identification tolerances remain. The result is not certified intersection-free.

Run the same `cad_mesh/remesh_others.ps1` saved-partition entry point. No build,
tests or remesh execution were performed for this change, as requested.
